
# Project Title
BookNook – Online Bookstore

# Project Overview
BookNook is a frontend-based online bookstore designed to provide users with a simple, attractive, and convenient platform for browsing and purchasing books and stationery products. The website follows a warm, cozy, scholarly design using Forest Green, Cream, and White colors. It simulates a real-world e-commerce bookstore experience with product browsing, search, filtering, cart management, checkout, wishlist, user authentication, gift wrapping, and order confirmation.

# Objective
The main objective of BookNook is to develop a responsive and user-friendly online bookstore where customers can:
•	Browse books and stationery by categories and subcategories. 
•	Search books by name, author, or ISBN. 
•	Filter products based on category, author, price, rating, and language. 
•	Add products to the shopping cart and adjust quantities. 
•	Add/remove products from a wishlist. 
•	Complete a simulated checkout process. 
•	Select payment and gift-wrapping options. 
•	View order details and expected delivery information. 

# Technologies Used
•	HTML5 – Structure of web pages 
•	CSS3 – Styling, responsive design, animations, and layout 
•	JavaScript – Application logic and interactivity 
•	React.js – Component-based frontend development 
•	Vite – Development and build tool 
•	Bootstrap – Responsive grid and UI components 
•	React Router – Page navigation 
•	LocalStorage – Storage of cart, wishlist, user, and order information 
Database: Not required, as this is a frontend-only project using JavaScript data and browser LocalStorage.

# Main Features
The project includes:
•	Home page with hero banner, categories, new arrivals, and author section 
•	Book product listing and product details 
•	Separate stationery section with subcategories 
•	Search bar with smoothly changing placeholder text 
•	Category and subcategory filtering 
•	Author, price, rating, and language filters 
•	Sorting products by price, rating, and name 
•	Shopping cart with quantity adjustment and total calculation 
•	Wishlist functionality 
•	Login and registration 
•	User profile and order history 
•	Checkout and order confirmation 
•	Delivery address, phone number, order date, and delivery date 
•	Gift wrapping option 
•	Related products 
•	About Us and Contact Us pages 
•	Responsive navigation bar and footer with social media links 

# Learning Outcomes
Through this project, I gained practical knowledge of React component development, React Router, state management, LocalStorage, JavaScript array operations, filtering and sorting, responsive UI design, Bootstrap, form handling, and e-commerce workflow implementation.

# Challenges
Some challenges included managing cart and wishlist data using LocalStorage, maintaining product filtering and subcategory relationships, updating the UI immediately after login/logout, handling order and gift-wrapping data during checkout, and creating a responsive design across different screen sizes.

# Conclusion
BookNook successfully demonstrates the development of a modern frontend e-commerce bookstore using React and related web technologies. The project provides a complete simulated shopping experience from product discovery to checkout and order confirmation while maintaining a clean, responsive, and user-friendly interface.
